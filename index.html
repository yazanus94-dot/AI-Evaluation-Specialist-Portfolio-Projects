AI Evaluation Specialist Portfolio

Python 3.11+MITCI

Three projects showing the core craft of an AI evaluation specialist: designing questions that expose model weaknesses, reviewing model output in a non-English language with a defensible rubric, and verifying confident claims against primary sources. Every artifact is machine-validated in CI.

Author: Yazan Aljabari

Projects

Adversarial Question Set

29 expert-level questions across networking, security, databases, programming and Unicode/time, each with trap type, gradable key points, likely wrong answer, and authoritative source. Reference answers re-derived in Python.

Arabic Tech Evaluation Set

30 evaluated Arabic/English responses with a weighted rubric with hard gates, an Arabic error taxonomy, terminology glossary, and corrected versions for every flawed response.

Source Verification Log

27 AI-style claims checked against primary sources: verdict, corrected statement, evidence summary, source links, rationale. 19 contradicted, 6 supported, 1 partial, 1 unverifiable.

Quick start

pip install pytest
cd adversarial-question-set-technology && python -m pytest -q
cd ../arabic-tech-evaluation-set && python -m pytest -q
cd ../source-verification-log && python -m pytest -q
